30 Release Build — packaged standalone ZIP with validation metadata.

LORE POLICY
- V15 Lore Essentials is the lore ceiling for this build.
- No new lore was added during website development.
- UNKNOWN entries remain unresolved.
- The canonical map is immutable.
- Illustrative visual assets never redefine geography, borders, culture or history.

NOTE
A full real-browser interaction test could not be completed in this environment; static validation and JavaScript syntax validation were completed. The package is designed to run offline because application data is embedded in app.js.
