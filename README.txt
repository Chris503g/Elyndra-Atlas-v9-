ELYNDRA ATLAS — Phase 4 v9 — INTERACTIVE VISUAL ATLAS

This build upgrades the Atlas into an interactive, animated visual encyclopedia focused on place visualization and exploration.

Highlights
- Interactive canonical map: pan, wheel/pinch-friendly zoom, layer filtering, animated markers and location drawer.
- Place-focused visual library with filters, keyboard-accessible cards and lightbox.
- Animated page reveals, atmospheric particles and hover micro-interactions.
- Command search with / or Ctrl/Cmd+K and keyboard navigation.
- Connected Codex detail pages with related entries and place imagery.
- Visual timeline and relationship network.
- Responsive desktop/tablet/mobile layouts.
- Offline-first: all critical app code and images are bundled locally.
- Illustrative visuals are explicitly separated from canonical map details.

FILES
index.html — application shell
app.js — bundled data and interactive application logic
styles.css — responsive visual system
data.json — canonical data reference
assets/ — canonical map and visual library

CANONICAL MAP SAFETY
The canonical map is immutable. Verified SHA-256:
89b11057e653927e36574f7e5f869836a749305b1aabf48c309fcae00786dbee

Do not replace, redraw, regenerate or alter the canonical map. Interactive overlays are navigation aids only and do not establish political borders.

VISUAL POLICY
Illustrative place art helps visualize Elyndra but does not silently establish new canon. Canonical-map-detail images are crops from the immutable supplied map.

LOCAL USE
Open index.html directly in a modern browser. No local web server is required for the bundled application.

ACCESSIBILITY
Keyboard search, focus states, semantic controls and prefers-reduced-motion support are included.
